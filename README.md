- Interactive graphs of response time (ms) for the last 30 minutes

### 🎨 [Co-Sketch](https://cosketch-co-sketch-frontend.vercel.app/) — Real-Time Collaborative Drawing App
An Excalidraw-style whiteboard where multiple users draw together in isolated rooms.

- Multiple concurrent users per room using **Canvas API + WebSocket**
- Rectangles, circles, and freehand rendering with **sub-100ms latency**
- Zoom and pan for smooth navigation at any scale
- Turborepo shared caching cut build times by **~40%**
